# 🪔 Diwali Sales Analysis 📊

This project explores and analyzes sales data from a Diwali festival marketing campaign. The goal is to extract insights from customer demographics and purchasing behavior to help businesses enhance marketing strategies and improve customer targeting.

## 📁 Project Files

- `Diwali_Sales_Data.csv`: Raw dataset containing transaction-level details of Diwali sales.
- `Diwali_Sales_Analysis.ipynb`: Jupyter Notebook performing data cleaning, EDA (Exploratory Data Analysis), and generating visual insights.

## 🧠 Key Insights

- Identification of top-performing cities and product categories.
- Gender-wise spending analysis and customer segmentation.
- Age group buying patterns and profession-based preferences.
- Recommendations for marketing based on regional and demographic data.

## 📌 Techniques Used

- Data cleaning using `pandas` (handling missing values, formatting, etc.)
- Data visualization using `matplotlib` and `seaborn`
- Grouping and aggregating sales data
- Insight generation and pattern recognition

## 🛠️ Tech Stack

- Python 3
- Jupyter Notebook
- pandas
- matplotlib
- seaborn

## 📊 Sample Visualizations

- Gender-wise Spending Bar Charts
- Age Group vs Spending Histograms
- City-Wise Purchase Analysis
- Product Category Heatmaps
